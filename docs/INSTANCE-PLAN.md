# Native stack instance planning

`gcontainers stack instance-plan SPEC [--expected-plan-sha256 DIGEST]` validates the native stack source, expands each declared replica into a stable domain-separated ID, and emits deterministic dependency waves. Each dependent instance requires every replica of each declared upstream service; reverse waves preserve shutdown order. The plan has a SHA-256 pin computed over canonical JSON with the planSHA256 field empty. Review recomputes the plan and rejects a stale pin. Secret reference names are omitted, only count returned. Image digests and service identifiers are operator-local data. Stable IDs are not generation-specific live identities. This is a planner, not an executor: no readiness health checks, runtime inventory, rollback, capacity admission, or MIPS authorization are inferred. Use existing preflight and capacity separately; do not apply this proposal.

## Runtime plan observation

gcontainers stack observe SPEC runc|crun --expected-plan-sha256 DIGEST recomputes the exact reviewed plan and correlates deterministic instance IDs with bounded live inventory. Per-instance missing/created/running/stopped/uncertain and dependency running counts are advisory; unrelated IDs are counted but not emitted. A pending operation is always uncertain, even if runtime reports running. A match does not establish workload ownership, image digest, guest identity or health. No create/start/restart/delete, no auto-reconciliation or authorization. Global recovery returns nonzero. Synthetic tests verify no unrelated names or secret references escape.
