# Private bundle snapshot preview

`gcontainers snapshot ABS_BUNDLE PRIVATE_PARENT --experimental` copies a local caller-owned restricted OCI bundle into a new private directory, bounds file count and bytes, rejects symlinks, hardlinks, special files, cross-device entries, unsafe owner/mode and privileged bits, and validates the resulting config and guest layout. It reports a deterministic content digest and never authorizes execution. The source may change after copying without changing the copied file. The private directory and owner read/execute-only files are not immutable against the same UID, nor are bind mounts on the same filesystem excluded. No automatic promotion, trusted image provenance or atomic source snapshot. Failed copies clean only the generated tree if identity still matches. The first-party isolated smoke test explicitly launches the copied bundle, with six namespace and cgroup readback tests passing on Linux with runc 1.5.3. Never use this preview for production.

Snapshot creation now uses a directory-handle-anchored private parent, checks source and destination open-file Linux mount IDs (including same-device mount crossings), rechecks root identities and synchronizes copied files and directories. Real isolated OCI fixture and mount-ID parser tests passed. This is not immutable, atomic, or protected from malicious same-UID changes. Actual bind-mount adversarial test remains outstanding.
