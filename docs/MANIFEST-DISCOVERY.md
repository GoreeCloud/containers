# Digest-pinned OCI manifest discovery

`gcontainers image discover-manifest HTTPS_ORIGIN REPOSITORY SHA256 SIZE --experimental` makes one bounded TLS-verified GET for a caller-pinned single OCI image manifest. It requires exact bytes, digest, media and valid config/layer descriptors, refuses redirects, authentication, index and artifact types, conflicting digests, external descriptor URLs and unsupported layers. At most eight tar or gzip layers, no automatic downloads, no credentials, no tag resolution and no execution. Returns only typed descriptors, not raw annotations. Synthetic local TLS registry tests verify rejection and success; no external registry contacted. Explicit caller-selected origins may be private or public; no service endpoint must expose this client to untrusted callers. Digest integrity is not publisher provenance or authorization.
