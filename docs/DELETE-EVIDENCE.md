# Deletion evidence

The rootless runtime adapter captures the original private state root and exact caller-owned runtime directory before delete. A successful runtime command only completes the mutation if the anchored ID path is absent and the original state root still matches. Retained directories, replacement symlinks, runtime failure or missing pre-deletion metadata preserve the pending journal. IDs journal and locks are reserved. runc list currently mistakes GoreeCloud's lock/journal directories for runtime containers, so no failed state query or noisy listing is used as absence proof. This confirms metadata absence, not independent process death or absence of an externally recreated instance; same-UID attacks and state-root/mount races remain outside the guarantee.
