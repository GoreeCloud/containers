# Local API preview

Run `gcontainers serve-local ABS_SOCKET --experimental` as a nonroot Linux user with an existing private socket parent and XDG_RUNTIME_DIR. It serves for at most 15 minutes in the foreground, on a new Unix-domain socket only, mode 0600. Kernel SO_PEERCRED restricts clients to the invoking UID. Connections and request sizes/timeouts are bounded. No TCP, remote management, credentials, mutation, identifiers or host paths are exposed. GET /v1/health reports capability status, GET /v1/journal reports the aggregate pending census (409 if recovery is required, 503 if unavailable). All other operations are rejected. Same-UID trust is not GoreeCloud Identity integration. Do not use in production. No MIPS authorization is implied; later remote and mutation interfaces require verified Identity, Mesh, GoreeShield and Wardveil integration, with GoreeCloud UI as the graphical design authority.

Opt-in runtime summary: serve-local ABS_SOCKET --runtime runc --experimental enables GET /v1/runtime-summary (otherwise 404). Bounded inventory supplies total/running/created/stopped/uncertain counts only; no IDs, PIDs, paths, annotations or raw responses. 409 on uncertainty, 503 on unavailable or changed inventory, no automatic repair. local-query ABS_SOCKET runtime-summary validates exact response keys, counter sum and policy flags. Same-UID Unix access is not GoreeCloud Identity or MIPS compliance.
